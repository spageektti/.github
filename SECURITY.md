# Security Policy

## Reporting Security Issues

If you believe you have found a security vulnerability in any project across this account, please **do not open a public issue or pull request**.

Instead, please report it via one of the following methods:

1. **GitHub Security Advisory:** Use the "Report a vulnerability" tab under the repository's **Security** tab (if available).
2. **Email:** Send details directly to **wiktor@perskawiec.cc**.

### What to include:
- The repository and branch/version affected.
- A description of the vulnerability and potential impact.
- Clear steps to reproduce or a minimal proof of concept (PoC).

I will acknowledge receipt within 48–72 hours and provide updates as the issue is investigated and patched.
